## 一、UART0/1初始化

教科书74页，给的是UART0初始化，考试考UART1

![image-20260704141827174](./image/20260704141832913.png)



### 1. 配置引脚功能

![img](./image/18.png)

GPA0CON寄存器的[7:4]和[3:0]要配置为0010

对应代码`GPA0CON |= 0x22`，0x22换算为10进制是0010 0010，对全是0的寄存器的0到7进行按位或，配置为0010 0010

如果是UART1的话，是配置CPA0CON的[19:16]和[23:20]，需要把0x22左移16位

对应代码`GPA0COn |= 0x22 << 4*4`

### 2. 配置UART0/1参数

8位数据位、1位停止位、无校验、正常模式

![image-20260704144355192](./image/20260704144355247.png)

对应代码`ULCON0 = (0x3 << 0) | (0 << 2) | (0 << 3) | (0 << 6)`

如果是UART1，对应代码就是把ULCON0换成ULCON1

### 3、配置UART0/1工作模式

![image-20260704144231049](./image/20260704144231191.png)

![image-20260704145045918](./image/20260704145045980.png)

中断或者polling模式、触发错误中断、时钟源PCLK

对应代码`UCON0 = (1 << 0) | (1 << 2) | (1 << 6) | (0 << 10)`

配置[1:0]和[3:2]都为01，把收发都配置为中断或者polling模式

如果是UART1，就把UCON0切换为UCON1。

![image-20260704145623007](./image/20260704145623071.png)

![image-20260704145818709](./image/20260704145818815.png)

禁止FIFO，对应代码`UFCON0 = 0`

### 4、计算波特率

![image-20260704145717650](./image/20260704145717707.png)

![image-20260704145857561](./image/20260704145857617.png)

PCLK时钟为66MHz，波特率115200，要计算UBRDIV0和UDIVSLOT0

## 二、中断初始化

![image-20260704152419366](./image/20260704152419509.png)

### 1. 配置中断引脚

![image-20260704154344720](./image/20260704154344835.png)

把key1和key2对应的[3:0]和[7:4]都配置为1111

对应代码`GPH0CON |= (0xFF << 0)`(0xFF 对应 0b1111,1111)

如果是只配置key1或者key2:

- Key1: `GPH0CON |= (0x0F << 0)`
- Key2: `GPH0CON |= (0x0F << 4)`

配置为下降沿触发：

![image-20260704154800691](./image/20260704154800747.png)

下降沿触发即Falling edge triggered

对应代码

- `EXT_INT_0_CON |= 2`：把[2:0]配置为0b010
- `EXT_INT_0_CON |= (2 << 4)`: 把[6:4]配置为0b010

取消屏蔽外部中断

![image-20260704155120669](./image/20260704155120734.png)

就是把第0位和第1位都配置为0

对应代码`EXT_INT_0_MASK &= ~0x3`把[1:0]通过按位与配置为0

## 三、Timer0/1初始化

![image-20260704161908562](./image/20260704161908694.png)

目标是设置1s触发一次Timer0的中断

### 1. 设置定时器初始值和比较值寄存器

初始值寄存器TCNTB0对应Timer0，TCNTB1对应Timer1，决定输出信号频率

比较值寄存器TCMPB决定输出信号占空比

根据预分配系数和分频值来计算，预分频系数是65，分频系数是16，那么初始值寄存器的值就是`66.7MHz/(65+1)/16=63162Hz`

占空比为50%，那么比较值寄存器的值就是初始值*50%，即31581Hz

### 3. ADC转换数据寄存器

为了获取ADC采样的数据，例如在定时器中断服务函数中读取

读取TSDATX0的数据：`x = TSDATX0 & 0x3FF` （10位ADC采样）

**0x3FF是何意味，如果是12位ADC采样呢？**

0x3FF是一个位掩码，表示只取低10位，其他位都清掉，12位的位掩码是0xFFF

```
  // 10 位 ADC
  x = TSDATX0 & 0x3FF;   // 取 0~1023

  // 12 位 ADC
  x = TSDATX0 & 0xFFF;   // 取 0~4095
```

## 六、makefile/交叉编译工具链分析/start.S

示例：

```makefile
led.bin: led.o start.o
	arm-linux-ld -Ttext 0xD0020010 -o key.elf $^
	arm-linux-objcopy -O binary key.elf $@
	arm-linux-objdump -D key.elf > key.dis

led.o: led.c
	arm-linux-gcc -c $< -o $@

start.o: start.S
	arm-linux-gcc -c $< -o $@

clean:
	rm *.o *.elf *.bin *.dis
```

主要步骤：

- arm-linux-gcc编译依赖文件（.c和.S文件），生成.o目标文件
- arm-linux-ld 链接器，基于.o文件生成.elf文件，设置代码段地址为0xD0020010
- arm-linux-objcopy 复制elf文件并转换为bin文件
