# 数学公式渲染说明

本博客已经接入 `remark-math`、`rehype-katex` 和 KaTeX 样式，可以直接在 Markdown 文章中写 LaTeX 数学公式。

相关配置位置：

- `astro.config.mjs`：启用 `remarkMath` 和 `rehypeKatex`
- `src/layouts/Layout.astro`：引入 `katex/dist/katex.css`
- `src/layouts/Layout.astro`：为块级公式添加横向滚动容器

## 推荐写法

### 行内公式

行内公式使用单个美元符号包裹：

```md
函数 $f(x,y)=x^2+y^2$ 在 $(0,0)$ 处取得极小值。
```

渲染效果会出现在正文同一行中，适合短公式、变量、坐标和条件。

### 块级公式

独立展示的公式使用双美元符号包裹：

```md
$$
f(x,y)=x^4+y^4-(x+y)^2
$$
```

块级公式适合较长公式、矩阵、分段函数、推导过程和需要单独居中的内容。

### 多行推导

多行推导建议使用 `aligned`：

```md
$$
\begin{aligned}
f'_x &= 4x^3 - 2(x+y) \\
f'_y &= 4y^3 - 2(x+y)
\end{aligned}
$$
```

### 矩阵

矩阵可以使用 KaTeX 支持的 `pmatrix`：

```md
$$
H=
\begin{pmatrix}
f_{xx} & f_{xy}\\
f_{yx} & f_{yy}
\end{pmatrix}
$$
```

## 常用数学记号

### 一阶偏导

如果希望显示撇号，可以写成：

```md
$$
f'_x=0,\qquad f'_y=0
$$
```

也可以使用更标准的偏导写法：

```md
$$
\frac{\partial f}{\partial x}=0,\qquad
\frac{\partial f}{\partial y}=0
$$
```

### 二阶偏导

```md
$$
f_{xx}=12x^2-2,\qquad f_{xy}=-2,\qquad f_{yy}=12y^2-2
$$
```

### Hessian 判别式

```md
$$
D=f_{xx}f_{yy}-f_{xy}^2
$$
```

判断条件可以写成列表：

```md
- $D>0,\ f_{xx}>0$：极小值；
- $D>0,\ f_{xx}<0$：极大值；
- $D<0$：鞍点；
- $D=0$：无法判断。
```

## 不推荐写法

### 不要使用 `\(...\)` 写行内公式

当前 Markdown 渲染链路推荐使用 `$...$`。不要写：

```md
\(f(x,y)\)
```

请改成：

```md
$f(x,y)$
```

否则公式可能不会进入 KaTeX 渲染流程，最终页面里会显示成普通括号文本。

### 不要把公式写进标题

不要写：

```md
## 判断 $(1,1)$
```

建议写成：

```md
## 判断 (1,1)
```

原因是目录生成器会读取标题文本。标题中包含 KaTeX 时，目录里可能出现重复的 MathML fallback 文本。

### 不要把普通文字插入公式块

不要把解释文字放在 `$$...$$` 中间：

```md
$$
H=
\begin{pmatrix}
12x^2-2 & -2\\
二元函数极值判断可以记成：
-2 & 12y^2-2
\end{pmatrix}
$$
```

应改成：

```md
所以 Hessian 矩阵为：

$$
H=
\begin{pmatrix}
12x^2-2 & -2\\
-2 & 12y^2-2
\end{pmatrix}
$$

二元函数极值判断可以记成：

$$
D=f_{xx}f_{yy}-f_{xy}^2
$$
```

## 转义规则

如果正文中需要显示普通美元符号，需要转义：

```md
价格是 \$10，而不是数学公式。
```

如果公式中需要显示中文，使用 `\text{}`：

```md
$$
f(1,1)\text{ 是极小值}
$$
```

## 验证方法

修改文章后，在项目根目录执行：

```sh
pnpm build
```

构建通过只能说明语法没有破坏站点。要确认公式是否真的渲染为 KaTeX，可以预览页面：

```sh
pnpm preview
```

然后在浏览器中打开对应文章，检查公式是否显示为排版后的数学公式，而不是原始 LaTeX 文本。

## 排查清单

公式没有渲染时，优先检查：

- 行内公式是否使用 `$...$`，而不是 `\(...\)`
- 块级公式是否使用完整成对的 `$$`
- 公式块中是否混入了普通中文说明
- LaTeX 环境是否完整闭合，例如 `\begin{pmatrix}` 和 `\end{pmatrix}`
- 标题中是否包含数学公式，导致目录显示异常
- 公式是否写在代码块中；代码块里的内容不会被渲染
